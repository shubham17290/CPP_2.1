# Priority Queue — Functions (Legacy)

Legacy functions folder for the max-heap priority queue. Contains one file per member function.

## Files

| File | Function |
|------|----------|
| `_01_push.cpp` | `push()` — insert element |
| `_02_pop.cpp` | `pop()` — remove top element |
| `_03_top.cpp` | `top()` — access top element |
| `_04_empty.cpp` | `empty()` — check if empty |
| `_05_size.cpp` | `size()` — number of elements |
| `_06_swap.cpp` | `swap()` — swap with another queue |
| `_07_emplace.cpp` | `emplace()` — construct in place |
