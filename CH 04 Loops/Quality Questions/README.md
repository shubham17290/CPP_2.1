# Quality Questions — CH 04 Loops

Curated, interview-style practice problems for this chapter. Each file is self-contained and compiles independently.

| # | File | Problem |
|---|------|---------|
| 1 | `_01_fibonacci_series.cpp` | Print first n Fibonacci numbers. |
| 2 | `_02_armstrong_number.cpp` | Check if a number is Armstrong. |
| 3 | `_03_gcd_lcm.cpp` | Compute GCD and LCM of two numbers. |

## How to run

```bash
g++ -std=c++17 -O2 -Wall -Wextra "Quality Questions/<file>.cpp" -o out
./out
```
