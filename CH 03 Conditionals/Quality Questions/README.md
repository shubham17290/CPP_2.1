# Quality Questions — CH 03 Conditionals

Curated, interview-style practice problems for this chapter. Each file is self-contained and compiles independently.

| # | File | Problem |
|---|------|---------|
| 1 | `_01_leap_year.cpp` | Check whether a year is a leap year. |
| 2 | `_02_grade_calculator.cpp` | Convert marks to grade using if-else. |
| 3 | `_03_vowel_consonant.cpp` | Check vowel or consonant using switch. |

## How to run

```bash
g++ -std=c++17 -O2 -Wall -Wextra "Quality Questions/<file>.cpp" -o out
./out
```
