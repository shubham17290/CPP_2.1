# Deque — Functions

Advanced `std::deque` operations: erase, clear, swap.

## Files

| File | Function |
|------|----------|
| `_01_erase.cpp` | `erase()` — remove element at position |
| `_02_clear_deque.cpp` | `clear()` — remove all elements |
| `_03_swap.cpp` | `swap()` — swap contents with another deque |
