# Map — Unordered Map — Functions and Methods

One file per `std::unordered_map` member function, demonstrating usage with inline comments.

## Folder: `02 functions and methods`

Common functions:
- `insert()` — insert key-value pair
- `operator[]` — access by key
- `at()` — safe access by key
- `erase()` — remove by key
- `find()` — find element
- `count()` — count occurrences
- `empty()` / `size()` — status queries
- `clear()` — remove all
- `swap()` — swap contents
