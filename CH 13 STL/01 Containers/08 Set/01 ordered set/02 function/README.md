# Set — Ordered Set — Functions

One file per `std::set` member function, demonstrating usage with inline comments.

## Folder: `02 function`

Common functions:
- `insert()` — insert element
- `erase()` — remove element(s)
- `find()` — find element
- `count()` — count occurrences
- `size()` / `empty()` / `clear()` — status queries
- `swap()` — swap contents
