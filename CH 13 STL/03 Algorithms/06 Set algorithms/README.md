# Set Algorithms

Range-based set operations on sorted inputs: union, intersection, difference, and symmetric difference.

## Files

| File | Algorithm | What it does |
|:--|:--|:--|
| `_01_union.cpp` | `set_union()` | Elements in either range |
| `_02_intersection.cpp` | `set_intersection()` | Elements in both ranges |
| `_03_difference.cpp` | `set_difference()` | Elements in the first range only |
| `_04_set_symmetric_difference.cpp` | `set_symmetric_difference()` | Elements in exactly one range |

## Practice Questions

| # | Challenge | Hint |
|--:|:--|:--|
| 1 | Compute the union and intersection of two sorted vectors. | Both inputs must be sorted. |
| 2 | Compute the difference in both directions. | `A - B` differs from `B - A`. |
| 3 | Compute the symmetric difference. | Elements in exactly one input. |
