# C++ DSA Practice

This repository contains my C++ practice programs, organized by chapter.

## Topics

- C++ basics, operators, and conditionals
- Loops and patterns
- Functions and binary numbers
- Pointers and arrays

## Run a program

Compile any `.cpp` file with a C++17 compiler:

```bash
g++ -std=c++17 path/to/file.cpp -o program
```

## Questions to check your understanding

- Can I explain the solution in my own words?
- Does it work for edge cases?
- Can I trace it with sample input?
- What are its time and space complexities?
- Can I solve it again without looking at the code?
